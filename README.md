# Sports Performance Analytics

Welcome to the official repository for the **Sports Performance Analytics** course. This repository contains all course materials, case studies, sample datasets, and project guidelines designed for undergraduate students exploring the intersection of data, sports science, and decision-making.

---

## Course Overview
This course provides an introduction to sports performance analytics for upperclassmen with little to no prior background in statistics or coding. Rather than getting bogged down in complex syntax, the focus is on **framing good questions, understanding analytical workflows, and translating data into actionable decisions** across three core domains:
1. **Athlete Tracking & Monitoring** (Load, physical output, and readiness)
2. **Strategy Optimization** (Tactical decisions and Expected Value)
3. **Scouting & Player Evaluation** (Talent identification and profiling)

## 🛠️ Tools & Resources
* **Spreadsheets (Excel / Google Sheets):** Used for primary data handling, descriptive summaries, and early case studies.
* **Case Studies:** Real-world scenarios focusing on evaluation, threshold management, and EV analysis.
* **Group Project:** A semester-long applied analytics project where students investigate a sports performance question from start to finish.
