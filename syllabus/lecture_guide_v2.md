# VERSION 2: INSTRUCTOR DAY-BY-DAY LECTURE GUIDE
Updated with Asynchronous Class & Integrated Project Work

---

## Week 1: Intro to Sports Analytics
- Class 1: Evolution of sports analytics and mapping the modern sports landscape.
- Class 2: Overview of the three domains (Tracking, Scouting, Strategy) and how data changes sports decisions.

## Week 2: Asking Good Questions
- Class 1: Translating sports intuition and coach questions into testable analytical problems. Case study discussion on defining the right questions before touching data.
- Class 2: Project Kickoff: Introduce group project expectations. Students begin brainstorming initial questions and identifying potential datasets (guarding against purely random "fishing" expeditions).

## Week 3: Data Collection, Quality & Ethics (Asynchronous Week Start)
- Class 1 (Asynchronous / At-Home): Identifying data sources, handling messy spreadsheets, and basic data hygiene via guided online module/reading. Expectation is to have data in hand for week 4.
- Class 2 (In-Class): Athlete data privacy, consent, and the ethics of tracking physical fatigue.

## Week 4: Descriptive & Diagnostic Frameworks
- Class 1: Defining the scope of analytics: Descriptive (what happened), Diagnostic (why it happened), and Predictive. 
- Class 2: Measures of center, spread, and distributions. Project tie-in: Students run preliminary descriptive stats on their project data. BONUS: Looking at group and positional difference

## Week 5: Data Visualization Taxonomy
- Class 1: Principles of honest charts; visualizing Quantities and Distributions in sports.
- Class 2: Visualizing Proportions and Relationships. Case Study / Project Lab: Students apply visualization techniques directly to their own project datasets.

## Week 6: Review & Midterm Exam 1
- Class 1: Midterm review session, Q&A, and workflow recap.
- Class 2: Midterm Exam 1.

## Week 7: Exploring Relationships & Correlation
- Class 1: Understanding association and how variables move together in sports.
- Class 2: Case Study / Project Lab: Hands-on session exploring relationships and diagnostic metrics using their project variables.

## Week 8: Simple Linear Regression & Prediction
- Class 1: Moving from correlation to predictive trend lines (simple linear regression).
- Class 2: Interpreting regression output in a sports context; applying model fits to project data where applicable.

## Week 9: Model Limits & Decision-Making Frameworks
- Class 1: Assessing model error, understanding limitations, and avoiding over-fitting.
- Class 2: Storytelling with data—translating analytical outputs for non-technical audiences (coaches/GMs).

## Week 10: Applied Scouting & Training Decisions
- Class 1: Talent evaluation thresholds, composite metrics, and player profiling.
- Class 2: Managing physical load, tracking internal/external metrics, and mitigating injury risk.

## Week 11: Applied Strategy Decisions & Expected Value (EV)
- Class 1: In-game decision making, risk vs. reward, and situational probabilities.
- Class 2: Introduction to Expected Value (EV) analysis in sports tactics.

## Week 12: Analytics Challenges & In-Class Work
- Class 1: Overcoming cognitive bias, pushback from traditional scouts, and organizational hurdles. Case study: analytics pushback: brainstorm organizational hurdles, cognitive bias, and communication solutions.
- Class 2: In-class working session and check-in for group projects.

## Week 13: Special Topics & Buffer Session
- Class 1: Flexible buffer class / catching up on curriculum pacing.
- Class 2: Advanced topic or guest focus (e.g., modern tracking tech or industry trends).

## Week 14: Group Project Working Sessions
- Class 1: Dedicated in-class data analysis and synthesis for group projects with instructor support.
- Class 2: Structuring presentations, formatting visuals, and finalizing recommendations.

## Week 15: Final Presentations
- Class 1: Group Project Presentations (Part 1).
- Class 2: Group Project Presentations (Part 2) & Final Peer Feedback.

## Week 16: Final Exam Review & Wrap-Up
- Class 1: Comprehensive final exam review session and Q&A.
- Class 2: Final Exam (held during finals week/schedule).
